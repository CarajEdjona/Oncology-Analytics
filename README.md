# Oncology-Analytics
An independent project using data science and genetics to analyze breast cancer cell features and scan for DNA mutations.

Data used: Wisconsin Breast Cancer Dataset

Libraries used: Pandas, Matplotlib, Scikit-Learn (StandardScaler), Streamlit Cloud

Tab 1 - Cell Shape Predictor (Phenotype):
Uses Logistic Regression and Standard Scaling to determine whether the cell shapes input by users are cancerous or safe.

Tab 2 - BRCA1 DNA Scanner (Genotype):
Scans for 4 known mutations on the BRCA1 breast cancer gene. Users can input a DNA Sequence provided in a table into a text box. Then, a pop up explains how that specific genetic mutation destroys the cell’s ability to repair its own DNA, causing the dangerous cell shapes flagged on Tab 1.

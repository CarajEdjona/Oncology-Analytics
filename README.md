# Oncology-Analytics
An independent project using data science and genetics to analyze breast cancer cell features and scan for DNA mutations.

Data used: Wisconsin Breast Cancer Dataset

Libraries used: Pandas, Scikit-Learn (StandardScaler), Streamlit

Tab 1 - Cell Shape Predictor (Phenotype):
Uses Logistic Regression and Standard Scaling to predict whether a sample is cancerous or noncancerous based on the cell measurements input by users.

Tab 2 - BRCA1 DNA Scanner (Genotype):
Scans for four preset DNA sequences linked to explanations of three BRCA1 mutations and one normal-reference example. Users can input a DNA Sequence provided in a table into a text box. Then, the site explains how harmful BRCA1 mutations can affect the cell’s ability to repair its own DNA and increase breast cancer risk.
